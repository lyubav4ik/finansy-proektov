# Финансы проектов

Веб-приложение для ручного учёта доходов и расходов по проектам внутри Битрикс24.
Совместная работа нескольких сотрудников: проекты, статьи, сотрудники, операции.
Расчёт прибыли и рентабельности по каждому проекту и за любой период.

## Возможности

- **Проекты** — создание, редактирование, удаление, бюджет, цвет.
- **Статьи доходов и расходов** — системные статьи (внешние/внутренние программисты,
  расходы на ИИ, аренда сервера, дивиденды, выручка) + возможность добавлять свои.
- **Сотрудники** — добавление сотрудников к проекту из пользователей портала Битрикс24.
- **Операции** — ввод доходов и расходов по проектам со статьями, датами, комментариями.
- **Отчёты** — доход, расход, прибыль, рентабельность; фильтры по проекту, статье,
  сотруднику и периоду; динамика по месяцам; разбивка по статьям.
- **Общие доступы** — глобальные права и права на конкретные проекты: можно выдавать
  роль сотруднику или целому отделу (включая иерархию) через штатный выбор Битрикс24.
- **Экспорт** — выгрузка операций в CSV.
- **Мультипользовательский доступ** — роли: Администратор, Полный доступ, Редактор, Просмотр.

## Стек

- Node.js + Express 4
- sql.js (SQLite в WASM) — никаких нативных модулей, запуск на любом Node
- Чистый HTML/CSS/JS, glassmorphism, mobile-first, микроанимации

## Запуск

```bash
npm install
npm start
```

Сервер поднимется на порту `3000` (переопределяется через `PORT`).
Переменные окружения (копия `src/.env.example` → `src/.env`):

| Переменная | Зачем |
|---|---|
| `PORT` | порт сервера (по умолчанию 3000) |
| `SERVER_URL` | публичный адрес приложения (для OAuth Битрикс24) |
| `OAUTH_CLIENT_ID` | client_id приложения в кабинете партнёра Битрикс24 |
| `OAUTH_CLIENT_SECRET` | client_secret приложения |
| `DB_PATH` | путь к файлу SQLite (по умолчанию `data/finansy.db`) |

## Установка в Битрикс24

1. Создайте приложение (тип «Встраиваемое») в кабинете партнёра или на портале.
2. Укажите URL установки: `<SERVER_URL>/oauth`.
3. При первом открытии администратор установит приложение — создадутся системные статьи.
4. Приложение откроется в рабочем столе/меню портала для всех сотрудников.

## Деплой на Galaxy

```bash
$env:VIBE_KEY="vibe_api_..." && node deploy-finansy.js
```

Скрипт создаёт/использует сервер Galaxy (`deploy-server.json` хранит id сервера),
пакует `src/`, деплоит, включает `accessPolicy: PUBLIC`.
