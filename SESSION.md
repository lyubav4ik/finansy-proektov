# Статус приложения «Финансы проектов»

## Что работает
- Учёт доходов и расходов по проектам (мультипользовательский, по порталу)
- 6 системных статей: выручка, внешние/внутренние программисты, ИИ, аренда сервера, дивиденды
- Свои статьи доходов и расходов
- Сотрудники проектов из пользователей портала (user.get)
- Операции с фильтрами по проекту/статье/типу/периоду, пагинация
- Отчёты: доход, расход, прибыль, рентабельность; по месяцам; по статьям
- Экспорт операций в CSV
- OAuth-установка: /oauth, повторная установка, удаление (/uninstall)
- Дизайн FoxStyle, mobile first, демо-режим (?demo)
